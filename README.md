# 📊 Aurora Beauty | Análise de Desempenho de Vendas e Cosméticos

Análise exploratória de dados e estudo de desempenho comercial de ponta a ponta para a marca de cosméticos e produtos de farmácia **Aurora Beleza & Bem-Estar**, cobrindo limpeza de dados, insights de negócio, métricas avançadas e visualizações em Python.

---

## 🎯 Objetivo do Projeto
Entender o desempenho comercial da empresa ao longo de 2025: identificar produtos e categorias mais rentáveis, mapear o desempenho regional e por canal de vendas, além de avaliar o impacto e a efetividade da política de descontos concedida.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python
* **Análise de Dados:** Pandas, NumPy
* **Visualização de Dados:** Matplotlib, Seaborn
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebooks
* **Controle de Versão:** Git & GitHub
